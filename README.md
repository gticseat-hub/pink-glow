# Pink Glow - Landing Page

Landing Page para el producto **Pink Glow: Suero Facial Revitalizante**.

## 🚀 Cómo usar

1. Clona el repositorio o descarga el ZIP.
2. Instala dependencias:
   ```bash
   npm install
   ```
3. Ejecuta en local:
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## 🌍 Deploy en Vercel

1. Sube este proyecto a un repositorio en GitHub.
2. Ve a [Vercel](https://vercel.com) y conéctalo con tu cuenta de GitHub.
3. Importa el repositorio y haz clic en **Deploy**.
4. Obtendrás un dominio gratuito tipo: `https://pinkglow.vercel.app`.
